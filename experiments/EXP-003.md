# EXP-003 · Один тип HR-вопроса

Статус: planned, not run · Владелец: не назначен · Связи: JOB-03 / CLM-005.
Основание: [SRC-038](../evidence/extracted/SRC-038.md), разделы 6–9.

## Гипотеза

Ответ по актуальному утверждённому источнику с отказом/эскалацией при нехватке основания уменьшает ручную нагрузку HR.

## Набор участников и данных

Выбрать один тип вопросов и 30–50 разрешённых исторических примеров (объём из SRC-038), получить актуальный источник и журнал изменений.

## Метод

Сравнить текущий бот, ручной ответ и Cowork по одной версии правил. Включить устаревший, неоднозначный и недоступный источник. На первом тесте только черновики, без персональных решений и отправки сотрудникам.

## Метрики и критерии

Точность и актуальность по эталону HR, корректная эскалация, время HR, покрытие ссылками. Пороги согласовать заранее с владельцем процесса; нулевая терпимость к раскрытию недоступных данных на тестовом наборе — предложенное ограничение.

## Решение по результату

Продолжить при согласованном качестве и измеримом снижении нагрузки; при нехватке данных сначала исправить базу знаний. Не распространять результат на весь HR-процесс.

## До запуска

Назначить владельца; получить разрешение на данные; зафиксировать baseline, эталон, выбранные пороги, окно, объём, правила исключения и план хранения. Незакрытые параметры блокируют запуск, но не подготовку сценария.

## Результат

Не получен. Заполнить: дата/версия, фактическая выборка, исключения, baseline, результат, негативные случаи, ограничения, ссылка на обезличенные данные, решение и подпись владельца. Не заполнять синтетическими успехами.
