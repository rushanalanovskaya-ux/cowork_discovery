# Размещение

Репозиторий: [cowork_discovery](https://github.com/rushanalanovskaya-ux/cowork_discovery), ветка `main`.

Владелец подтвердил открытый доступ ко всему подготовленному содержимому после уведомления о внутренних материалах, интервью и коммерческих гипотезах. Для этой публикации используется public visibility.

Обновление: выполнить `python3 scripts/check.py`, `python3 -m unittest discover -s tests -v`, затем commit и `git push origin main`. GitHub Actions настроен на проверку структуры и тесты. Защита ветки и CODEOWNERS ещё не настроены.
