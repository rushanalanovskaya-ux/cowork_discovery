# Журнал решений

Ни одно решение ниже пока не утверждено. Предложения созданы при формировании PDLC и не подменяют решения команды.

| ID | Решение на рассмотрение | Статус | Условие принятия |
|---|---|---|---|
| DEC-001 | Вести отдельно исходный roadmap, новые рекомендации и фактический статус реализации | proposed | Product и Engineering согласуют источник истины |
| DEC-002 | Выбрать один end-to-end сценарий ближайшего пилота | proposed | Данные, эталон, владелец и capacity доступны |
| DEC-003 | Сделать проверяемость результата и контроль доступа обязательными ограничениями пилота | proposed | Согласована матрица рисков и acceptance criteria |
| DEC-004 | Передавать в SDD версионный пакет с источниками, scope, тестами и метриками | proposed | Сверка с реальным SDD-репозиторием |

Для принятия создать запись по [шаблону](../templates/decision.md), указать владельца, дату, альтернативы, основание, влияние, связанные IDs и ссылку на ревью. Не выставлять approved только потому, что документ создан агентом.
