# Контроль качества PDLC и продукта

`scripts/check.py` проверяет структуру знаний, существование ссылок, связи claims/MVP/specs, диапазоны входов приоритизации и Ready-гейт. Это проверка качества репозитория, не тест реализации Cowork.

Синтетические fixtures ниже — примеры ожидаемых расчётов для будущей QA-постановки. Они не являются интервью, клиентскими данными или результатами продукта:

- `fixtures/table-reconciliation.json`: допустимый join, неразрешённый ключ и независимый ожидаемый итог; численность строк и агрегатов различается намеренно.
- `fixtures/metrics.json`: завершённые/ошибочные задачи и неизвестная приёмка для проверки знаменателей.

Реальные регрессионные кейсы добавляет QA после получения исходников, правил и разрешений. Связь каждого AC с тестом фиксируется в SDD.
